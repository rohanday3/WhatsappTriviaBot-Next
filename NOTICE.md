# Third-party notices

## Baileys

Baileys is an MIT-licensed, unofficial WhatsApp Web client library maintained by WhiskeySockets. This project pins a specific Baileys release for reproducibility.

## The Trivia API

When `THE_TRIVIA_API_ENABLED=true`, questions may be retrieved from The Trivia API. Its public question data is provided under the Creative Commons Attribution-NonCommercial 4.0 International licence. Commercial use requires an appropriate subscription and API key.

## Open Trivia Database

When `OPENTDB_ENABLED=true`, fallback questions may be retrieved from the Open Trivia Database. Open Trivia DB states that its data is provided under the Creative Commons Attribution-ShareAlike 4.0 International licence.
